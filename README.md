# RequestFlow API

**Proyecto 001 — Backend API REST**

RequestFlow API es una API backend para la gestión de solicitudes institucionales o empresariales. El sistema permitirá crear, asignar, consultar y hacer seguimiento a solicitudes, incorporando autenticación, roles, permisos, historial de cambios, comentarios, métricas operativas y documentación técnica.

## Objetivo del proyecto

Construir un proyecto backend serio de portafolio profesional, aplicando buenas prácticas en desarrollo de APIs REST, bases de datos relacionales, autenticación, seguridad básica, pruebas, documentación, Docker, Git/GitHub y despliegue.

## Stack técnico previsto

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Pydantic
- JWT
- RBAC
- Passlib / bcrypt
- Pytest
- Docker
- Swagger / OpenAPI
- GitHub Actions
